# Adil Higgsfield Skill

出典: Adil Alimzhanov（[@adilinthewild](https://x.com/adilinthewild)、"The Higgsfield Guy"）が2026年7月8日に投稿したスレッド
（https://x.com/adilinthewild/status/2074543910060527820 ）。Seedance 2.0・4K・Claude（Fable 5）監督・Higgsfield完結で作った2分/8シーンの短編映画の制作知見。

このリポジトリで `mcp__Higgsfield__generate_image` / `generate_video` / `show_characters` / `show_reference_elements` などを使うときは、以下の原則を優先的に適用する。

## 1. 180度ルールを守る（構図・カメラ）

- AI生成でも映画文法のミスはそのままミスとして現れる。2人のキャラクターが会話するシーンで、両方が同じ方向（例: 左）を向いていると、壁に向かって話しているように見えてしまう。
- 対策: キャラクター間に「見えない線」を引き、カメラは常にその線の片側に固定する。プロンプトにも視線の向き（例: 「Aは画面右を向いてBと向き合う」）を明示する。
- マルチショット・マルチシーンの動画では、シーンをまたいで同じ空間ルールを保つこと。

## 2. 感情の連続性は言葉で書く

- モデルは前のシーンで何が起きたか（キャラクターが直前まで泣いていた、等）を知らない。文脈を引き継がせないと、直前に泣いていたキャラクターが数秒後に何事もなかったように笑う、といった破綻が起きる。
- 対策: シーンをまたぐ感情・身体的状態の変化は、必ずプロンプトの文章として明示する。
  - 例: `slightly red eyes, traces of recent crying`
- 実務フロー: まずClaudeにシーン間のストーリー文脈（直前に何が起きたか）を渡し、その状態を反映した一文をプロンプトに追加させてから生成する。

## 3. 声の一貫性はプロンプトの文言で固定する

- Seedanceはキャラクターの見た目に合わせて声を自動生成する。
- 一度キャラクターの声が決まったら、その声の描写（トーン・話し方・特徴）を**すべてのショットで一字一句そろえて**プロンプトに書く。表現を変えると声も変わってしまう。
- 声の説明文はキャラクターシートと一緒に固定テキストとして保管し、コピペで使い回す。

## 4. 単発登場のキャラクターは参照画像なしでテキストのみでOK

- 一度きりしか出ないキャラクター（例: スタンドで名前を叫ぶ祖父）は、参照画像・キャラクターシートを用意せず、テキストプロンプトだけで一発生成してよい。
- キャラクターシートを作る/参照するのは「複数ショットで再登場させる主要キャラクター」に絞る。単発キャラにまで律儀にシートを用意するのは無駄。

## 5. デエイジング／リエイジングは「大人版シートの再投入＋年齢差分プロンプト」

- 顔の同一性を保ったままキャラクターの年齢を変える（例: 18歳若返らせる）には、ゼロから新しいキャラクターを作らない。
- 手順:
  1. 既存の（大人版などの）キャラクターシート／参照画像を再度入力として使う（`show_characters` / `show_reference_elements` で呼び出す）。
  2. 年齢に応じた具体的な差分をプロンプトで指定する（例: 「7歳のサンティアゴ、シャツに手描きの番号」）。年齢そのものだけでなく、年齢を感じさせる小道具・ディテールも書く。
  3. これにより「サンティアゴだと分かる」レベルの同一性を保ったまま年齢だけ変えられる。

## 6. バッチ全体が外れたらプロンプトを疑う（シードのガチャは最後の手段）

- バッチ生成の結果が全部イマイチなとき、**同じプロンプトのままシードだけ変えて再実行するのはクレジットの無駄遣い**。原因はほぼプロンプト側にある。
- 正しい順序:
  1. プロンプトの何が悪いか特定する（被写体・動作・舞台・カメラ・感情descriptionのどれかが曖昧/矛盾していないか）。
  2. プロンプトを修正する。
  3. 修正後のプロンプトでそのバッチ（例: バッチ4）を再実行する。
- 「同じ言葉のまま祈るように再実行」を繰り返さない、というルールがプロジェクト内で最もコスト削減に効いたとのこと。

## 7. 実例ワークフロー：Higgsfield完結・Claude監督の短編映画

Adilの制作例（2分・8シーン）の構成:

- **映像モデル**: Seedance 2.0（4K出力）
- **監督/演出設計**: Claude（Fable 5）にストーリー・シーン割り・各ショットの演出意図（構図・感情・声）を設計させる
- **制作環境**: Higgsfield内で完結（外部ツールへの持ち出しなし）

このリポジトリでHiggsfield MCPを使って同様のワークフローを組む場合の対応:

| Adilの原則 | 対応するHiggsfield MCPツール |
|---|---|
| キャラクターシートの管理・再投入 | `mcp__Higgsfield__show_characters`, `mcp__Higgsfield__show_reference_elements` |
| モデル選定（Seedance等の判断） | `mcp__Higgsfield__models_explore`（`action: 'recommend'`） |
| 画像/動画生成 | `mcp__Higgsfield__generate_image`, `mcp__Higgsfield__generate_video` |
| 4K化・高解像度化 | `mcp__Higgsfield__upscale_video`, `mcp__Higgsfield__upscale_image` |
| バッチ結果の確認 | `mcp__Higgsfield__job_display`, `mcp__Higgsfield__show_generations` |
| 複数シーンの短編を体系立てて作る | `mcp__Higgsfield__get_workflow_instructions` で該当ワークフローの有無を確認してから着手 |

## 生成前チェックリスト

キャラクターが登場するショットをHiggsfieldで作る前に、以下を確認する。

- [ ] 複数ショットに再登場するキャラクターか？ → Yes ならキャラクターシート/参照を用意・再利用。単発なら省略してテキストのみで良い。
- [ ] シーンをまたぐ感情・身体的状態の変化はプロンプトに文章で書いたか？
- [ ] キャラクターの声の描写は前のショットと一字一句同じか？
- [ ] 2人以上が会話するショットで、視線の向き（180度ルール）は矛盾していないか？
- [ ] 年齢を変える場合、ゼロから作らず既存シートを再投入し、年齢差分のディテールをプロンプトに足したか？
- [ ] バッチ結果が全滅したとき、シードだけ変えて再実行していないか？ まずプロンプトの修正から。
