# Floyoでの作り方 — 解説動画（Remotion）

`FLOYO_MIGRATION.md` と `wfaia/floyo-workflow.md` の内容を、ナレーション付きの
約2分15秒の動画にしたもの。9スライド構成（タイトル／全体フロー／素材／開始フレーム／
Floyoグラフ／二コマ打ち／ラン運用／検品／締め）。ナレーションはseed_audio（Arthur）。

ローカルでのレンダ:
```bash
cd works/hashikko-bill/floyo-guide
npm install
npm run render   # out/floyo-guide.mp4
```
書き出し済みmp4は generated.json の `floyo_guide_video_v1` を参照。
