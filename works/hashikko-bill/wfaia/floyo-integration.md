# Floyo組み込み提案 — キャラクターシート完成後の全体フロー

WFAIAの規定は2つだけ押さえればよい。

1. **作品と同時にFloyoワークフローを1点以上提出する（必須）**。制作自体は任意のAIツールでよい。
2. 審査は「AIの偶然ではなく作り手の意志と仕事」を、**提出されたワークフロー込み**で見る。
   入賞時はワークフロー・プロンプトの提出義務がある。

つまり「Floyoで全部作る」必要はない。**どこか1工程をFloyoに正式に担わせ、
その工程のラン履歴を制作ログとして提出できる状態にする**のが規定どおりの最小構成で、
かつ審査思想（プロセス評価）に一番効く。

## 全体フロー（キャラクターシートが起点）

```
【正本】CHARACTER BIBLE（01 CORE〜詳細シート）      ← いま作っているもの
   │  デザインの正。全生成物はここに照合される
   ▼
【開始フレーム】ショット表どおりのCANON準拠スチル     ← 済（generated.json）
   │  シートを参照画像に生成→1体ずつCORE照合
   ▼
【Floyo】 hashikko-i2v-stopmotion ワークフロー        ★ここが提出物
   │  Load Image → Resize/Pad → I2V(Kling/Wan) →
   │  2コマ打ち化 → Film Grain → 書き出し
   │  1ショット=1ラン。ラン名=ショットID
   ▼
【編集】カット繋ぎ・文字入れ・音（ローカル）
   ▼
【提出】アニメ部門(16:9) と 広告部門(9:16) ＋ 同じワークフローを両方に添付
```

## なぜこの分担が「規定どおり」で強いのか

- **規定の充足**: I2V工程がまるごとFloyo上にあるので、「ワークフロー1点以上」を
  両部門とも同じ1本で満たせる。
- **プロセス評価に直結**: Floyoのラン履歴が「78カットのコンテ → ショット表 →
  1ショット1ラン」という意志の連鎖の証拠になる。ラン名にショットIDを付ける
  運用（`floyo-workflow.md`）はこのため。
- **キャラクターシートが審査資料になる**: 「シートを参照に生成し、COREと照合して
  から動かした」という一文は、キャラクターデザイン審査観点（アニメ部門の第一項目）
  への直接の答えになる。シート画像そのものを補足資料に添える。

## 手順（シート完成後、そのまま実行できる形）

| # | やること | 場所 | 目安 |
|---|---|---|---|
| 1 | Floyoにログインし、新規ワークフローを `hashikko-i2v-stopmotion` の名前で作成 | Floyo | 10分 |
| 2 | `floyo-workflow.md` のグラフ構成どおりに6ノードを並べる（Load Image → Resize/Pad → I2V → フレーム処理 → Film Grain → 書き出し） | Floyo | 30分 |
| 3 | 試験ラン1本：`generated.json` の `b1_hiiragi` のURLを開始フレームに、共通サフィックスを付けて5秒生成 | Floyo | 15分 |
| 4 | 試験ランの結果で「顔にパーツが足されていないか」を確認。足されていたらnegativeを強める（このNG例もラン履歴に残ることが逆に評価材料になる） | Floyo | 15分 |
| 5 | アニメ部門ショット表（`anime-shots.json`＝12+予備2）と広告部門（`ad-shots.json`＝7）を1ショット1ランで実行。ラン名＝ショットID | Floyo | 2〜3時間 |
| 6 | 書き出したクリップをローカルで編集（文字・音はここで載せる。生成物に文字を入れていないのはこのため） | ローカル | 半日 |
| 7 | 提出フォームで両部門に応募し、**同じワークフローのリンク/エクスポートを両方に添付**。説明文は `floyo-workflow.md` 末尾の下書きを使う | フォーム | 30分 |

## 提出パッケージ（部門ごと）

- 本編（アニメ=16:9・1〜5分 ／ 広告=9:16・15〜60秒）
- Floyoワークフロー `hashikko-i2v-stopmotion`（両部門共通・1本）
- 補足資料: CHARACTER BIBLE のシート（キャラデザ審査観点への答え）、
  絵コンテ `storyboard.html` のスクリーンショット数枚（演出力・ディレクションの証拠）

## 注意（変わらないルール）

- 建物外形は映さない（Y7未確定）。霧と窓の色だけで建物を語る。
- 大和・雲井・李・トメ・鵜飼は顔にパーツを足させない。negativeを絶対に外さない。
- 一画面に複数社の色が出るのは協働カットのみ。
