# 本編ラフカット自動アセンブリ（正典）

**目的**: 生成済みの全カットから「英語ナレ入り・5分以内・1本のmp4」を自動で組む。

## 使い方（ローカルPC・2コマンド）

```bash
cd ~/repos/public && git pull
node works/hashikko-bill/setup-workspace.mjs        # 素材をデスクトップへ（未済なら）
node works/hashikko-bill/edit/assemble.mjs          # → ~/Desktop/hashikko_honpen_v1.mp4
```

- 日本語ナレ版は `--ja` を付ける（両方作って聴き比べ可）
- ffmpegが無ければ `brew install ffmpeg`（または `npm i ffmpeg-static`）

## 何が組み上がるか

- **構成**: C00a古地図 → A章(C02〜C06) → **キャラ紹介モンタージュ9カット**(B1柊→1Fトメ→…→7Fひかり) → B〜I章(C07〜C73) → C76依頼書 → C78ラスト → **最終フレーム14秒ホールド**(締めナレの余韻+編集でタイトルを載せる場所)
- **尺**: カット群280秒+アウトロ14秒=約4分54秒。絵コンテの実尺配分を保ったまま自動スケール(×約0.86)
- **ナレーション**(英語版が既定。各章の頭に配置):

| 配置カット | ナレ | 内容 |
|---|---|---|
| C00a(0秒) | vo_opening_en | 世界の果てのビル、白紙の依頼 |
| C07 | vo_seq_b_en | 依頼の到着 |
| C17 | vo_seq_c_en | 四十年ぶりの全社会議 |
| C28 | vo_seq_d_en | 管理人が倒れた朝 |
| C37 | vo_seq_e_en | 十一分間の約束 |
| C48b | vo_seq_f_en | 裏切り |
| C55 | vo_seq_g_en | 三階のほんとうの話 |
| C63 | vo_seq_h_en | 納品の日 |
| C71 | vo_seq_i_en | 八社目（葬式にかけて） |
| C73 | vo_ending_en | 締め（ラスト+アウトロにかけて） |

- **音声はナレのみ**（クリップ音声は外してある）。SE/BGM・テロップ(telops.html)・CM字幕は編集ソフトで重ねる
- 未ダウンロードのカットは自動でスキップして警告表示（後から素材を足して再実行すればOK）

## 調整のしかた

- 尺配分を変える: `assemble.mjs` 冒頭の `BUDGET` / `OUTRO` / `INTRO_SEC`
- ナレ位置を変える: `NARR` 配列（カット番号→ナレidの対応）
- 特定カットだけ差し替え: デスクトップ`12_本線I2V/`の同名mp4を置き換えて再実行
