## 2. 開始フレームの作り方（Floyo移行後の最初の作業）

絵コンテ78カットのうち、本番化するショットは **鉛筆パネルではなく
「キャラ図版＋美術設定から起こしたCANON準拠スチル」を開始フレームにする**。

- 単カットのスチルはこれまで通りの確定手法で生成：
  **承認済み図版を第1参照＋COREを第2参照＋要点の言語化1行**
- ビル外観カット（sb01等）は `building/WORLD_REFERENCE.md` の質感読解が正。
  ただし**外形はCANON未承認**（丸窓＝目に見える問題・アンテナ本数）— 承認後に着手
- 画面内に文字を入れない（看板は無地、文字は編集で載せる）

## 3. I2V実行（`wfaia/floyo-workflow.md` のグラフをそのまま組む）

- 1ショット＝1ラン、ラン名＝ショットID（例 `sb14_hikari_mailroom`）
- duration 5s／2コマ打ち化／フィルムグレイン弱〜中
- 共通サフィックスとnegative（morphing / redesign / extra facial features / text）を**毎回**付ける
- **顔にパーツを足させないキャラ（最重要検品項目）：**
  大和（口なし・白目にワイン虹彩）／雲井（上寄り黒点2・口なし）／
  李（顔なし柱状頭）／トメ（ほぼ無地の細長顔）／鵜飼の家族（縫い目の口）
- リテイクはランを複製してseed変更。ラン履歴＝制作ログとしてWFAIAのプロセス評価に提出

## 4. 尺と音の正（動画コンテが基準）

- カット割り・実尺は `animatic/src/cuts.json`（78カット・299秒）が正。
  I2Vは5s固定で生成→編集で `sec` に合わせて詰める
- 台詞・ナレの仮音声27本は `generated.json` の `kind: narration_audio`。
  本収録に差し替えるまではこのwavをそのまま編集タイムラインへ
- 完成した動画コンテ（mp4）をFloyo作業中の**尺のリファレンス**として常に横に置く

## 5. 検品フロー（Floyo側でも変えない）

1. 生成カットの1フレーム目と該当キャラの CORE／06 CONTINUITY CHECK を突き合わせ
2. 顔パーツ増殖・衣装色ズレ・プロップ違いがあれば即リテイク（正典プロップは03シート参照）
3. OKカットのみ `generated.json` に追記（job/ラン名・URL・使用参照を記録）— 台帳の一元管理を維持
