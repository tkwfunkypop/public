## 2.5 セリフ・音・文字の方針（正典）

- **会話は喃語**：キャラクターは「うー」「いー」のような**言葉と認識できない声**で会話する。
  演技は口ではなく**首の傾き・肩・手振り**で見せる（口なしキャラに口を足さない）。
- **字幕・テロップ・タイトルは編集ソフトで後載せ**。画面に合成する類の文字は映像内に一切入れない。
- **作品世界内の文字（プロップの文字）は生成に含めてよい**：看板・プレート・帳簿・号外・依頼書などの
  紙面には**「この世界のオリジナル架空文字」**（実在の日本語・アルファベット・数字ではない、
  判読不能な手書き風グリフ）を描いてよい。**なんて書いてあるかは編集字幕で伝える**ため読めなくて正解。
  実在文字が読み取れてしまう場合のみNG。
- **BGMは映像に入れない**（編集で）。**SE（効果音）はOK**（ノック、歯車、風、食器など）。
- 各カットの「シーン表記＋I2Vプロンプト」は **`storyboard/i2v-prompts.json`** が正
  （`startframes.html` の各カードにも同じ内容を表示）。
  Floyoでは**スタートフレーム画像＋このプロンプト**をセットで送る。

## 3. I2V実行（`wfaia/floyo-workflow.md` のグラフをそのまま組む）

- 1ショット＝1ラン、ラン名＝ショットID（例 `sb14_hikari_mailroom`）
- **生成モデルは MiniMax H3（`minimax_h3`）**。対応尺 5〜15秒・16:9・2K。
  各カットの**生成秒数は `storyboard/i2v-prompts.json` の `gen_sec`** が正
  （実尺 `sec` を下限5秒で切り上げ。生成→編集で実尺に詰める）。
  `startframes.html` の各カードにも「生成◯s／実尺◯s・MiniMax H3」を表記済み。
- 2コマ打ち化／フィルムグレイン弱〜中
- 共通サフィックスとnegative（morphing / redesign / extra facial features / text）を**毎回**付ける
- **顔にパーツを足させないキャラ（最重要検品項目）：**
  大和（口なし・白目にワイン虹彩）／雲井（上寄り黒点2・口なし）／
  李（顔なし柱状頭）／トメ（ほぼ無地の細長顔）／鵜飼の家族（縫い目の口）
- リテイクはランを複製してseed変更。ラン履歴＝制作ログとしてWFAIAのプロセス評価に提出

## 4.5 セット正典とモブ（社員）差別化ルール

- **セット正典**：繰り返し出る場所は `generated.json` の `kind: set_reference`
  （`set_rooftop` / `set_stairwell` / `set_corridor` / `set_elevator` / `set_caretaker` /
  `set_kitchen7f` / `set_observatory4f` / `set_perfume5f` / `set_print6f` /
  `set_workshop2f` / `set_office3f` / `set_office1f`）が正。
  **同じ場所のカットは必ず該当セットを参照に入れて生成**し、背景をブレさせない。
  廊下の七つの扉は各社の階色（1F白／2F琥珀／3F緑／4F青緑／5F青／6F菫／7Fマゼンタ）で塗り分け＝正典。
- **集合カット**：会議（sb17/25/39）、食卓（sb67）、階段運び（sb64）、覗き（sb16）、
  往復（sb48）、七分割（sb10）等は**主要キャラ全員の図版をマルチ参照**で渡して生成する。
  在席メンバーが欠けていないかが最重要検品項目。
- **モブ（社員）差別化**：群衆は原則**主要キャラ本人のみで構成**し、汎用の社員を発明しない。
  やむを得ず背景モブを置く場合は「所属階の色の腕章」＋「簡略なボタン目」を必ず付け、
  主要キャラと見分けがつくようにする。
- **シート準拠（絶対則）**：全キャラクターの表情・サイズ感・造形は
  `character-sheets.html` の各シート（CORE／承認図版）が正。
  **シートを作っていない人物は絶対に登場させない**（白髪の老婆・子供・動物・
  モコモコの生き物などの「発明キャラ」は即NG）。
  生成AIはキャラ名の字面（例: トメ→おばあさん）に引っ張られて別人を描くため、
  プロンプトには必ず「名前ではなく参照画像から複写する」旨と、
  トメ＝黒ロングドレスの長身白面／雲井＝黒髪が顔を覆うパッチワークローブ／
  大和＝黒髪ロング×プラムワンピ、の言語化を併記する（CHARACTER FIDELITY節）。
  検品では「参照と一致しない人形が1体でもいれば不合格」。
- **登場人物の閉集合（絶対則）**：`character-sheets.html` に掲載された14キャラ
  **以外の人物は絶対に登場させない**。
- **同一キャラの重複禁止（絶対則）**：**同じキャラが同じシーン（同じ画面）に
  2人以上写ってはいけない**。1カット内で各キャラは最大1体。検品項目に含める。
- **ひかりの弁当ポーズ（正典所作）**：七尾ひかりが弁当を持っているシーンでは、
  **必ず両手を頭上に上げて弁当箱（積み荷）を支えて持つ**。
  手を離した荷物が宙に浮く表現は禁止（トランク塔も本人が支えているか、ストラップで固定されていること）。
  プロンプトには "HIKARI holds the stack ABOVE HER HEAD with BOTH HANDS raised;
  boxes never float detached" を明記する。
