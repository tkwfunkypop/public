# Instagram開設チェックリスト — エピソード型

作成日: 2026-08-10
状況: TikTokフォロワー102人到達。エピソード型の主戦場であるInstagramを開設するタイミング。TikTokは並行継続する（やめない。役割は発見エンジンのまま）。

---

## 開設初日にやること（投稿より先にプロフィールを完成させる）

- [ ] **名前欄に検索語**: 「名前｜シリーズ名（理学療法士）」形式。名前欄はInstagram内検索の対象。例: 「◯◯｜カルテには書けない話」
- [ ] **自己紹介文4行**: ①何者か（PT＋医療職夫婦など） ②何を投稿するか（患者さんとの話・医療職カップルの現実） ③注記（エピソードは特定できないよう再構成しています） ④更新頻度
- [ ] **プロアカウント（クリエイター）に切り替え**: インサイト（保存・シェア・リーチ）が見えないと運用判断ができない
- [ ] **TikTokプロフィールにインスタリンクを設置**（TikTokはプロフィールリンクが貼れる数少ない場所）
- [ ] 表紙テンプレを1種類確定（色・フォント・レイアウト固定。グリッドが「連載」に見えることが最優先）

## 初動2週間の投稿プラン

**原則: ゼロから書かない。TikTokの勝ちネタから移植する。**

- [ ] TikTokのインサイトで上位3〜5本を確認（再生数だけでなくコメント数・シェア数で選ぶ）
- [ ] 勝ちネタをカルーセル（1枚目フック→会話再現→問いかけ締め）に再編集して初週に投入
- [ ] 1本目は「スタンス表明」（ネタ帳#30）。ハイライト「はじめての方へ」に固定する
- [ ] 頻度: 週3〜4本。開設直後の毎日投稿は不要（新規アカウントはどうせリーチが低い。質とグリッドの見た目を優先）
- [ ] ストーリーズは初日から毎日（投稿がない日も裏話・アンケートで動かす）
- [ ] 9投稿たまるまでは「グリッドの第一印象を作る期間」と割り切る（プロフィールに来た人が3秒で「連載だ」と分かる状態が目標）

## TikTok→Instagramの導線（開設告知）

- [ ] TikTokで「インスタ始めました」単発告知はしない（伸びない）。代わりに**「この話の続き（本音）はインスタに書きました」型**で2〜3本に分けて誘導
- [ ] TikTokの固定コメントにインスタの存在を書く
- [ ] 以後、エピソードの「表版はTikTok・本音の追記はインスタのキャプション」と役割を分けると両方見る理由ができる

## ハッシュタグ初期セット（コピペ用・投稿ごとに5〜10個選ぶ）

`#理学療法士 #理学療法士の日常 #医療職 #医療職と繋がりたい #医療職カップル #看護師との恋愛 #リハビリ #病院勤務 #夫婦の日常 #エッセイ`
※2ヶ月目にインサイトを見て、流入のあるタグだけ残して入れ替える。

## 期待値の設定（重要）

- 新規アカウントは最初の2〜4週間リーチがほぼ出ない（アカウントの信頼形成期間）。**ここで判断しない**
- 最初の目標はフォロワー数ではなく「プロフィールアクセス→フォロー転換率5%」と「1投稿あたりコメント3件」
- TikTok 102人のうち何割かが移ってくれば初期コメント欄は回る。初期コメントには全返信
- 判断のタイミングは90日後（`strategy-episode.md` のロードマップ通り）

## やらないこと

- 開設直後のフォロー回り・いいね回り（アルゴリズムに雑アカウント扱いされる）
- TikTok動画の透かし付きリール転載（リーチ抑制。素材から書き出し直す）
- 数字が出ないことを理由にした2週間以内の方針変更
