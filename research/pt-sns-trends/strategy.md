# 理学療法士アカウント SNS戦略 — TikTok編 / Instagram編

作成日: 2026-08-10
前提: `README.md`（伸びている投稿の傾向リサーチ）の結論を土台に、これからアカウントを伸ばすための実行戦略に落とし込んだもの。

---

## 0. 両プラットフォーム共通の土台（先に決めること）

リサーチの結論はシンプルだった: **勝敗は資格ではなく「コンセプトの一言化」と「ターゲット固定」で決まる**（ソロ整体／1分極伸びが好例）。戦略の前に次の2つを決める。

1. **ターゲットをひとりに絞る**
   例: 「座り仕事で夕方に首・肩が限界になる30代デスクワーカー」「産後の腰痛ママ」「転倒が怖くなってきた70代の親を持つ子世代」。
   ※リサーチ上、デスクワーカー向けは実績最大・競合最多。産後・シニア転倒予防・スマホ首の学生は空きニッチ。
2. **コンセプトを一言に命名する**
   「○○整体」「1分△△」のように、投稿名・ハッシュタグ・シリーズ名として毎回使える固有名詞にする。
   命名テンプレ: `時間 × 部位・悩み × 独自手法`（例: 「15秒デスク整体」「寝たまま産後リセット」）。

**役割分担（これが戦略の核）**
- **TikTok = 発見エンジン**。フォロワーゼロでも興味グラフで新規に届く。認知獲得とネタのA/Bテスト場。
- **Instagram = 信頼と転換のエンジン**。保存される「悩み別辞典」としてストックし、プロフィール→LP/予約/講座へ刈り取る。
- 同じコンセプト名・同じ人格で運用し、TikTokで勝ったネタをInstagramに再編集して流す。

## 1. TikTok戦略 — 「毎日1ワザ、秒で効く」

### 1-1. コンテンツの型（4フォーマット、比率6:2:1:1）

| 比率 | フォーマット | 具体 |
|---|---|---|
| 6 | **即効ワザ実演** | 7〜30秒。「○秒で△△が楽になる」を冒頭0.6秒のテロップ＋動きで約束→1ワザだけ実演→効果確認。リサーチ上これが再生の主戦場 |
| 2 | **Before/After・施術リアクション** | 可動域が一瞬で変わる瞬間・患者の「えっ⁉」を切り取る。視覚だけでフックが成立する唯一の型 |
| 1 | **職業あるある・人格** | PTあるある・現場ネタ・自己開示。信頼と親近感の担保。バズより「この人」化が目的 |
| 1 | **トレンド便乗** | 流行音源・フォーマットに教育テロップを乗せる。アルゴリズムへの相乗り枠 |

### 1-2. 1本の設計図（即効ワザ実演の場合）

```
0.0-1.0秒  悩み名指しテロップ「夕方、首が限界な人だけ見て」＋症状の再現動作
1.0-3.0秒  「○秒でゆるむ」と結果を先に宣言（数字必須）
3.0-20秒   1ワザを3手順で実演（手順番号テロップ・カウントダウン表示）
ラスト2秒   効果の確認動作＋「できたらコメントで『できた』って教えて」
```

- 縦画面・顔出し・字幕全文（消音視聴前提）。
- 専門用語は1本1個まで。使うなら即言い換える（「僧帽筋、ここの筋肉ね」）。
- エビデンス一言（「○○の研究でも〜」）は差別化になる。ただし薬機法・医療広告的な断定（「治る」）は避け「ゆるむ・楽になる」で統一。

### 1-3. 運用ペース

- **最初の90日は週5〜毎日投稿**。TikTokは1本ごとに抽選なので試行回数がそのまま学習速度。週1回のバッチ撮影（2〜3時間で10本撮り）で回す。
- コメントは最初の1時間に全返信。質問コメントには**動画で返信**（返信動画はネタ切れ防止と親密度の両取り）。
- シリーズ化する: 「#15秒デスク整体 その12」。プロフィールからの連続視聴を生む。

### 1-4. KPIと判断基準

| 指標 | 目安 | 判断 |
|---|---|---|
| 完視聴率（視聴維持） | 短尺で70%〜 | 低ければ冒頭1秒を作り直す（内容ではなくフックの問題） |
| 保存・シェア率 | 再生の1.5%〜 | 高い型を翌週の本数配分に反映 |
| プロフィールアクセス→フォロー | 10%〜 | 低ければプロフィール文とシリーズ名を見直す |

- **月次で「勝ちネタトップ5」を選定** → Instagramへ再編集・横展開（後述）。
- 伸びない90日を過ごしたら、ネタではなく**ニッチ（ターゲット）を疑う**。

### 1-5. 刈り取り

TikTokはフォロー関係が弱く外部リンクも貼りにくい。**TikTok内で売ろうとしない**。プロフィールにInstagram・LINE・LPを置き、「詳しいやり方の図解はインスタに保存版がある」と動画内で口頭誘導する。

## 2. Instagram戦略 — 「保存される悩み別辞典」

### 2-1. コンテンツの型（3本柱）

| 柱 | 頻度 | 役割 |
|---|---|---|
| **リール** | 週3 | TikTokの勝ちネタを再編集して投入。新規リーチ枠。※TikTokロゴ透かし入り動画はリーチ抑制されるため、必ず元素材から書き出し直す |
| **カルーセル（図解10枚）** | 週1〜2 | 「保存」を稼ぐ主力。悩み別ストレッチを辞典化する。Instagramのアルゴリズムは保存数を最重視 |
| **ストーリーズ** | 毎日 | 日常・Q&A・アンケート・投稿の裏側。親密度シグナルを維持し、既存フォロワーのフィード表示率を守る |

### 2-2. カルーセルの設計図（保存させる10枚）

```
1枚目   フック表紙:「知らないと損する ○○が楽になる3つの順番」
        （数字・損失回避ワードをタイトルに。リサーチ実例で閲覧数が激増した型）
2枚目   共感: 症状のあるある描写「こういう時ありませんか」
3-8枚目 本編: 1枚1手順。写真＋矢印＋秒数
9枚目   まとめ1枚（この1枚だけ見れば復習できる=保存理由を作る）
10枚目  CTA:「保存して明日の朝やってみて」＋他の辞典への誘導
```

### 2-3. プロフィール＝LPとして設計する

- 名前欄に検索語を入れる: 「◯◯｜15秒デスク整体（理学療法士）」— 名前欄はInstagram内検索の対象。
- ハイライトを導線として固定: 「はじめての方へ」「部位別もくじ」「予約/講座」「お客様の声」。
- グリッドは表紙テンプレを統一し、部位別に色分け。プロフィールに来た人が「辞典だ」と3秒で分かる状態にする。
- 実用9 : PR1 の比率を守る。院・講座の宣伝投稿は10本に1本まで（リサーチ上、組織公式が伸びない最大の理由がPR過多）。

### 2-4. KPIと判断基準

| 指標 | 目安 | 判断 |
|---|---|---|
| 保存率（保存/リーチ） | 3%〜 | カルーセルの生命線。低ければ「まとめ1枚」の有無と表紙を見直す |
| プロフィールアクセス→フォロー転換 | 5〜10% | 低ければグリッド統一とハイライトを見直す |
| 外部リンククリック | 月次で増加 | 刈り取りの実力値。LP側の計測とセットで見る |

### 2-5. 刈り取り

Instagramが唯一まともにリンクを踏ませられる場所。プロフィールリンク→LP（このリポジトリのLP制作スキルの出番）。ストーリーズのリンクスタンプは講座募集・キャンペーン時に集中投下する。

## 3. 制作パイプライン（両立させる仕組み）

```
週1バッチ撮影(10本)
   │
   ├─→ TikTok: 週5本 先行投稿 ＝ A/Bテスト
   │        │
   │        └─ 月次で勝ちネタTOP5を選定
   │                 │
   ├─→ Instagramリール: 勝ちネタを再編集(透かしなし書き出し) 週3
   │
   └─→ カルーセル: 勝ちネタを図解化 週1-2
              │
              └─→ ストック(辞典)が貯まる → LP・講座への導線強化
```

**90日ロードマップ**
- **1ヶ月目**: ニッチ検証。4フォーマット×計40本をTikTokに投入し、反応の出る悩み×型を特定する。Instagramはプロフィール整備と週1カルーセルのみ。
- **2ヶ月目**: 勝ち筋に集中。比率を勝ち型に寄せ、シリーズ名を確定。Instagramのリール転載を本格化。
- **3ヶ月目**: 刈り取り設置。ハイライト・LP・LINE導線を整え、実用9:PR1の範囲で初回の募集/予約導線をテスト。

## 4. やらないことリスト

- 同業者（PT）向けの専門発信 — 別アカウントでやる。混ぜると一般向けアルゴリズムが濁る
- 「治る」「改善を保証」等の断定表現 — 医療広告規制リスク。「ゆるむ/楽になる」で統一
- 網羅型の長尺解説 — 伸びるのは1ワザ完結。網羅はカルーセル辞典とLPの役割
- TikTok動画の透かし付きリール転載 — リーチ抑制の無駄打ち
- 毎日のPR投稿 — 実用9:PR1を死守
